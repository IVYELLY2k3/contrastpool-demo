What you are seeing
  1. Each subject is a 30×30 connectivity matrix (how strongly regions talk to each other), built from noisy fake signals.
  2. Group 1 secretly has a few boosted connections. Those are the "hidden clues".
  3. The contrast graph subtracts the group averages, so the clues light up.
  4. Classifying with only the top-K contrast edges ignores most of the noise. That is the core idea of the paper.

Note: this demo uses plain group averages. The real ContrastPool also learns attention weights over regions and subjects and uses a trained graph neural network (see the Python file).
